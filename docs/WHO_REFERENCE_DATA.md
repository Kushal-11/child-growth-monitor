# WHO reference data used by the mobile app

The result screen's sex-and-age reference targets come only from the official
WHO Child Growth Standards Excel workbooks listed below. The displayed target
is the WHO median (`z = 0`); the displayed reference interval is `z = -2` to
`z = +2`. These are population comparison standards, not measurements of a
child.
